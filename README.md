# dlap-drift-game

## D LAP 每日工作表（checklist/）

员工手机用的每日工作表，扫 QR 码就能用，不用登入。

- 网址：https://kit6025.github.io/dlap-drift-game/checklist/
- QR 码图片：`checklist/qr-code.png`（可以直接打印）
- 按「WhatsApp 发送 PDF」：手机直接做好 PDF 报告（不用上网），再用分享选单发到 WhatsApp 工作群
- 要改工作内容：打开 `checklist/index.html`，找「工作内容 —— 要修改就改这里」，
  照 `编号 | 华文 | English | 时间` 的格式改就可以。
  华文里写（一、三、六）只在那几天出现；写（SF & SP）、（SF/Paragon）只给那些分行。
